Vice Grid — an offline web app that turns your photos and a caption into a multi-panel GTA 6-style poster cover (2×2 grid, hero + strip, or triptych), with per-panel crop and position, drag-to-arrange panels, a Vice City sunset / neon / noir grade, and bold condensed caption lettering, exported as PNG in 1080×1080, 1080×1350, or 1920×1080.

## Run it

Serve `app/` with any static server and open it in desktop Chrome — no build step, no network:

```sh
node serve.ts
# open http://localhost:8080
```

Load your photos (or use the two model-made samples), click a panel to select it, drag inside it to pan its photo, drag the panel chips to reorder, type your caption, pick a grade, and hit Export PNG.
